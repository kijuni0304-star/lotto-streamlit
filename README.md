# 로또 번호 생성기

Streamlit으로 만든 웹 앱입니다. 1~45 중 메인 번호 6개와 보너스 번호 1개를 생성합니다.

## 로컬에서 실행

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. Streamlit Community Cloud에서 GitHub로 로그인합니다.
3. **New app**을 선택하고 저장소와 `main` 브랜치를 고릅니다.
4. Main file path에 `app.py`를 입력하고 **Deploy**를 누릅니다.
